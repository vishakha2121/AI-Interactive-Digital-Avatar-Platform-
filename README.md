## 🌟 Project Overview

The **AI Interactive Digital Avatar Platform** is an immersive, AI-powered virtual companion that brings digital characters to life. It combines cutting-edge technologies including Large Language Models, speech synthesis, emotion detection, and 3D animation to create engaging and natural human-avatar interactions.

### 🎯 Key Highlights
- **Real-time Conversation**: Powered by Google's Gemini AI for intelligent, context-aware dialogue
- **Facial Animation**: 3D avatars with realistic facial expressions and lip synchronization
- **Emotion Detection**: Analyzes text and voice to detect and respond to emotions
- **Multilingual Support**: Real-time translation and speech in multiple languages
- **Voice Interaction**: Speech-to-text and text-to-speech capabilities

### 💡 Why This Project?
This project demonstrates the convergence of multiple AI technologies:
- ✅ **LLM Integration** - Gemini API for natural conversations
- ✅ **Computer Vision** - Emotion detection from text/voice
- ✅ **Speech Synthesis** - TTS and STT technologies
- ✅ **3D Graphics** - Real-time avatar rendering with Three.js
- ✅ **Full-Stack Development** - React + FastAPI + SQLite

## 🚀 Getting Started

### Prerequisites

| Requirement | Version |
|-------------|---------|
| **Node.js** | 16.0+ |
| **npm** | 8.0+ |
| **Python** | 3.10+ |
| **pip** | 22.0+ |
| **Git** | 2.30+ |

### Installation Steps

#### 1️⃣ Clone the Repository
```bash
git clone https://github.com/vishakha2121/AI-Interactive-Digital-Avatar-Platform-.git
cd AI-Interactive-Digital-Avatar-Platform-

# Navigate to backend
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Setup database
alembic upgrade head
python seed_database.py

# Start the server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Open a new terminal
cd frontend

# Install dependencies
npm install

# Start the development server
npm start

# The app will open at http://localhost:3000
